# SaidApp

Um aplicativo web/mobile feito para marcar saidas com amigos e fazer novas amizades. Feito em React Native.

## Como baixar

1. Clone o repositorio em alguma pasta do seu computador

   ```bash
   git clone https://github.com/dyingtrojan/SaidApp.git
   ```

2. Na pasta, rode npm install para baixar as dependencias

   ```bash
   npm install
   ```

3. Para iniciar o aplicativo, rode esse comando.

   ```bash
   npx expo start
   ```
